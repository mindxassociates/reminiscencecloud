# Start here

This folder is the complete Reminiscence Cloud website. The public site is generated by Astro and hosted through GitHub Pages. Pages CMS is the editor used for routine copy, contact details, and articles. GitHub stores the source and publishes saved changes.

## Before launch

The English and Simplified Chinese content and screenshot-based visual system have been added. The original `/en/...` links are preserved through routes or redirects. In Pages CMS, review **Site settings / 网站设置** and connect the approved secure consultation service for `/en/book/` and `/zh/book/` before launch.

The added nature and interior photographs are sourced from Pexels. Their source pages and photographers are recorded in `IMAGE-CREDITS.md`; keep that file in the repository when publishing or replacing images.

The local workspace could not reach the package registry, so the first complete production build must be verified by the included GitHub Actions workflow after upload.

The website privacy policy and HIPAA Notice are bilingual drafts. Do not remove their review banners or treat them as adopted notices until Sharon confirms the legal practice entity, privacy contact, effective date, actual vendors/data flows, state-specific requirements, and whether 42 CFR Part 2 applies. The HIPAA draft links to the February 2026 HHS model used for comparison.

## Common tasks

- Change contact information: Pages CMS → Site settings.
- Update page copy: Pages CMS → the matching English or Chinese page.
- Create an article: Pages CMS → Resources → New.
- Ask technical support for layout, navigation, deployment, domain, or recovery changes.

Never upload client records, inquiries, intake forms, credentials, or private clinical documents. Review the use of testimonials under applicable professional ethics and advertising rules before launch.
